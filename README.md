# Встановлення і запуск

## Завантаження проекту на сервер

```
# Завантаження всього проекту (Скрипт запускаємо з пк)
scp -r /path/to/parser-importer username@server_ip:/path/to/destination/
```

## Встановлення залежностей

Підключіться до сервера та встановіть необхідні Python пакети:

```
ssh username@server_ip
cd /path/to/project/
pip install -r requirements.txt
```

## Налаштування конфігурації

1. Відкрийте файл .env в nano

```
cp .env.example .env
nano .env
```

2. Налаштування:
   WC_URL=https://your-site.com
   WC_KEY=your_consumer_key
   WC_SECRET=your_consumer_secret
   WC_USERNAME=your_wp_username
   WC_PASSWORD=your_wp_password

### Де взяти WC_KEY і WC_SECRET

1) Зайдіть у адмін-панель шопу
2) Перейдіть до WooComerce > Settings > Advanced > REST API
3) Створіть новий ключ: Add key > Введіть будь-який текст в полі Description > Поставте в полі Permissions - Read/Write > Generate API key
4) На сторінці відобразяться два значення Consumer key та Consumer secret це і є WC_KEY і WC_SECRET

### Де взяти WC_USERNAME та WC_PASSWORD

1) Зайдіть у адмін-панель шопу
2) Перейдіть до розділу Users
3) Оберіть свій акаунт (наприклад samsam2231)
4) Прокрутіть до розділу Application Passwords
5) Створіть новий пароль: введіть будь-яке ім'я паролю у полі New Application Password Name > Натисніть Add Aplication Password
6) Ім'я паролю та пароль який з'явиться на сторінці це і є WC_USERNAME та WC_PASSWORD

3. За необхідності відредагуйте config.ini:

'''
nano config.ini
'''

PARSER

1) max_retries - кількість спроб запиту до донора або  при невдачі
2) requests_delay - затримка між запитами в секундах
3) batch_size - товари імпортрують пачками. Для прикладу якщо розмір пачки 5, то спочатку спарситься 5 товарів, а потім ці 5 товарів заливаються на WooComerce. Це зроблено для збільшення продуктивності
4) start_with_category - з якої за номером категорії почнеться парсинг. Категорії знаходяться у файлі data/categories.json. Корисно для відновлення парсингу з того місця де він зупинився.
5) start_with_page - сторінка з якої розпочнеться парсинг
6) start_with_item - елемент на сторінці з якого розпочнеться парсинг
   ВАЖЛИВО! Дані про те на якій категорії зупинився парсер зберігається у файлі data/saved_progress. Він оновлюється під час парсингу

IMPORTER

1) download_images_before_import - чи потрібно завантажувати картинки перед заливанням їх на WC чи заливати тільки посилання на ці картинки. True - так, False - ні. Корисно коли WC не може самостійно завантажити картинки (я у випадку з поточним донором)
2) add_custom_description_style - чи додавати кастомні стилі до опису товарів. Ці стилі завантажуються з файлу custom_description_style.css
3) requests_delay - затримка між запитами до WC в секундах
4) max_retries - максимальна к-сть спроб запиту до WC при помилках
5) default_swatches_size - розмір іконок у плагіні Swatches у пікселях

## Підготовка WordPress/WooCommerce

1. Додати функції в functions.php
   1) Скопіюйте вміст файлу functions.php
   2) Зайдіть в адмін-панель
   3) Перейдіть у Apperance > Theme File Editor > functions.php
   4) Вставте скопійований код після наявного. УВАГА! Для конкретно цього шопу, я вже виконав цю дію, тому ще раз не потрібно копіювати один і той самий код

## Запуск допоміжного скрипта categories.py

Щоб зібрати файл категорій categories.json використовуйте скрипт utils/collect_categories_urls.py. Цей скрипт працє тільки на ПК, на сервері - ні. Збір категорій треба робити тільки раз перед парсингом конкретного донора. Для конкретно цього донору збір категорій вже виконаний

```
python utils/collect_categories_urls.py
```

## Запуск парсера

```
python main.py
```

# Хід парсингу та імпорту

## Етапи роботи скрипта

1. Ініціалізація
   Скрипт завантажує налаштування з config.ini та категорії з categories.json. Використовується функція collect_product_data для парсингу та import_batch для імпорту.
2. Обробка сторінок категорії
   Для кожної категорії скрипт:

- Переходить по сторінках товарів
- Збирає посилання на товари
- Парсить дані кожного товару

3. Батчевий імпорт
   Коли накопичується батч товарів (розмір визначається в config.ini - batch_size), відбувається імпорт до WooCommerce.

## Індикатори прогресу

Під час роботи ви побачите кілька прогрес-барів:

1. Прогрес парсингу категорій:
   - Опис: Показує прогрес обробки категорій
   - Одиниця: кат. (категорії)
   - Значення: поточна категорія / загальна кількість категорій

```
Категорія: Home & Garden > Kitchen & Dining > Cookware & Bakeware: 45%|████▌     | 9/20 кат.
```

2. Прогрес парсингу сторінок категорії:
   - Опис: Прогрес парсингу сторінок поточної категорії
   - Одиниця: стр. (сторінки)
   - Значення: поточна сторінка / загальна кількість сторінок

```
Парсинг сторінок категорії: 23%|██▎       | 5/22 стр.
```

3. Прогрес парсингу товарів на сторінці:
   - Опис: Збір товарів з поточної сторінки категорії
   - Одиниця: продукт
   - Значення: зібрано товарів / загальна кількість на сторінці

```
Збір продуктів на сторінці: 67%|██████▋   | 85/128 продукт
```

4. Прогрес імпорту батчу товарів:
   - Опис: Підготовка даних батчу для імпорту
   - Одиниця: т. (товари)
   - Значення: оброблено товарів / загальна кількість у батчі

```
Завантаження зображень: 60%|██████    | 3/5 зображень
```

5. Прогрес завантаження зображень
    - Опис: Створення варіацій товарів у WooCommerce
    - Одиниця: в. (варіації)
    - Значення: створено варіацій / загальна кількість
```
Імпорт варіацій батчу: 40%|████      | 2/5 в.
```

## Збереження прогресу
Скрипт автоматично зберігає прогрес у файлі saved_progress.json:
```
{
  "last_parsed_category": 5,
  "last_parsed_page": 12,
  "last_parsed_item": 1
}
```
При перезапуску парсинг продовжиться з місця зупинки, якщо в config.ini змінено параметри start_with_* на параметри з цього файлу

# Модулі

Проект складається з кількох взаємопов'язаних модулів, кожен з яких відповідає за певну функціональність. Нижче представлено детальний опис структури та компонентів системи

## main.py
Точка входу в програму, яка координує роботу всіх компонентів.
Функціональність:
- Завантаження списку категорій з categories.json
- Ініціалізація процесу парсингу через collect_product_data
- Передача батчів товарів до імпортера через import_batch

## parser.py
Основний модуль для збору даних з сайту Fruugo. Містить всю логіку парсингу товарів, категорій та їх варіацій.

### Функції:
1. collect_product_data(categories, batch_handler) - Головна функція модуля, яка керує процесом збору даних:
- Ітерує через категорії починаючи з start_with_category
- Відстежує прогрес через tqdm прогрес-бар
- Зберігає прогрес у saved_progress.json

2. collect_category(category, batch_handler) - Збір товарів з окремої категорії:
- Пагінація сторінок категорій
- Збір посилань на товари через PRODUCT_LINK_SELECTOR
- Обробка батчів розміром batch_size

3. collect_product_page(url) - Парсинг окремої сторінки товару:
- Витягування основних даних: назва, ціна, опис, бренд
- Обробка варіацій товару (розміри, кольори)
- Збір зображень через селектори IMAGES_SELECTOR та IMAGE_SELECTOR
- Парсинг категорій через CATEGORIES_SELECTOR

4. make_request(method, url, **kwargs) - HTTP-клієнт з обробкою помилок:
- Повторні спроби до max_retries
- Затримка між запитами requests_delay
- Використання curl_cffi для обходу захисту

### Налаштування:
Налаштування парсера (з config.ini):
- max_retries = 5 - кількість спроб при невдачі
- requests_delay = 1 - пауза між запитами (сек)
- batch_size = 5 - розмір батчу товарів
- start_with_category = 3 - номер категорії для старту

## importer.py
Модуль відповідає за завантаження спарсених даних до WooCommerce через REST API.

### Функції:
import_batch(products) - Головна функція імпорту батчу товарів:
- Підготовка даних для WooCommerce API
- Створення атрибутів та термінів
- Завантаження зображень (опційно)
- Створення товарів та їх варіацій

ensure_terms_exist(attr_id, terms) - Перевірка та створення термінів атрибутів:
- Пошук існуючих термінів через API
- Створення нових термінів при необхідності
- Додавання HEX-кодів для кольорів через webcolors

upload_image_to_wc(image_url, retries=3) - Завантаження зображень до медіатеки WordPress:
- Скачування зображення з URL
- Валідація розміру та формату
- Завантаження через /wp/v2/media API endpoint

get_or_create_category_chain(breadcrumb_string) - Створення ієрархії категорій:
- Парсинг breadcrumb (тобто рядка категорії) рядка (розділювач ">")
- Рекурсивне створення батьківських категорій
- Повернення ID кінцевої категорії

### Налаштування 
Налаштування імпортера:
- download_images_before_import = true - попереднє завантаження зображень
- add_custom_description_style = true - додавання CSS стилів
- requests_delay = 3 - затримка між запитами до WC
- default_swatches_size = 48 - розмір іконок

## collect_categories_urls.py
Допоміжний скрипт для автоматичного збору URL категорій з сайту через Selenium:
- Запуск undetected_chromedriver для обходу захисту
- Автоматичне закриття cookie-попереджень
- Навігація через меню "Shop by department"
- Рекурсивний обхід всіх підкатегорій
- Збереження результату у categories.json

Особливості:
- Використовує WebDriverWait для очікування елементів
- Обробляє як посилання (<a>), так і кнопки (<button>)
- Автоматичне повернення до попереднього рівня меню
- Працює тільки на локальній машині (не на сервері)

## Взаємодія модулів
- main.py завантажує категорії та запускає collect_product_data
- parser.py парсить товари та передає батчі до batch_handler
- importer.py обробляє батчі та створює товари в WooCommerce
- logger.py забезпечує логування на всіх етапах
- Прогрес зберігається у saved_progress.json для можливості відновлення
